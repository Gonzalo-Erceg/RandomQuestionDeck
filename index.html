¡Conociendo a nuestros mentores!

Con mucho entuciasmo los alumnos del programa de Desarrollo web Full-Stack programamos un juego interactivo para usarlo en la presentacion de nuestros mentores de J.P. Morgan. Este juego consiste en una pila de cartas donde cada una tiene una pregunta totalmente aleatoria junto al nombre de un mentor (el cual debera responder la pregunta).

Esta pagina esta creada utilizando la biblioteca ThreeJS que facilita la creacion y visualizacion de graficos 3D en la web utilizando WebGL. Ademas utilizamos GSAP, una biblioteca de Javascrip altamente eficiente y versatil para crear animaciones Web. El escenario y todos los objetos 3D fueron creados utilizando el programa Blender para luego exportarlos en formato .glb.
